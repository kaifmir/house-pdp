# Housing.com Mobile Homescreen

Mobile-friendly homescreen for Housing.com property search experience.

## Features

- Property type navigation (Buy, Project, Rent, Plot, Commercial, PG)
- Animated search placeholder with typing effect
- Recent searches section
- Property recommendations
- Smart buy section
- Sticky bottom navigation

## Setup

1. Create a new repository on GitHub
2. Run these commands:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

3. Enable GitHub Pages:
   - Go to repository Settings
   - Click on "Pages" in the left sidebar
   - Under "Source", select "main" branch
   - Click "Save"

Your site will be available at: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`
